# Практична робота №2

## Тема
Створення першого репозиторію та виконання коміту

## Мета роботи

- навчитися створювати репозиторії GitHub;
- ознайомитися зі структурою репозиторію;
- навчитися створювати та редагувати файли;
- виконати перший коміт;
- переглянути історію змін.

---

# 1. Коротка теорія

## Репозиторій

Репозиторій (Repository) — це місце для зберігання проєкту та його файлів. У репозиторії можуть міститися текстові файли, програмний код, документи, зображення та інші матеріали.

## Коміт (Commit)

Коміт — це збереження змін у репозиторії. Кожен коміт містить опис виконаних змін, дату та автора.
