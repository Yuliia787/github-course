# Практична робота №1

## Тема
Реєстрація та знайомство з GitHub

## Мета роботи

- створити власний обліковий запис GitHub;
- ознайомитися з інтерфейсом платформи;
- навчитися знаходити основні елементи GitHub;
- ознайомитися зі структурою профілю та репозиторію.

---

# 1. Коротка теорія

## Що таке GitHub?

GitHub — це вебплатформа для зберігання файлів, керування версіями та спільної роботи над проєктами. Сервіс дозволяє розробникам, студентам і викладачам зберігати свої проєкти в репозиторіях та відстежувати зміни у файлах.

## Основні поняття

### Repository (Репозиторій)

Репозиторій — це місце для зберігання проєкту та його файлів.

### README.md

README.md — це файл з описом проєкту. Він автоматично відображається на головній сторінці репозиторію.

### Issues

Issues використовуються для постановки завдань, повідомлень про помилки та обговорення роботи над проєктом.

### Projects

Projects допомагають планувати роботу та контролювати виконання завдань.

### Pull Requests

Pull Requests використовуються для перевірки та об'єднання змін перед їх додаванням до основної версії проєкту.

# 2. Завдання

## Завдання 1

Створіть обліковий запис GitHub.

## Завдання 2

Заповніть власний профіль:

- додайте фото;
- вкажіть ім'я та прізвище;
- напишіть коротку інформацію про себе.

## Завдання 3

Знайдіть у власному профілі:

- ім'я користувача (Username);
- Repositories;
- Followers;
- Following.

Занесіть отриману інформацію до звіту.

## Завдання 4

Ознайомтеся з вкладками:

- Repositories;
- Projects;
- Issues;
- Pull Requests.

Для кожної вкладки запишіть її призначення.

## Завдання 5

Перейдіть до профілю викладача.

Визначте:

- ім'я користувача;
- кількість репозиторіїв;
- назву будь-якого репозиторію;
- дату останнього оновлення одного з репозиторіїв.

## Завдання 6

Дайте відповіді на контрольні запитання.

1. Що таке GitHub?
2. Що таке репозиторій?
3. Для чого використовується файл README.md?
4. Для чого використовуються Issues?
5. Для чого використовуються Projects?
6. Для чого використовуються Pull Requests?
