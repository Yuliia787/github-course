---

# 1. Коротка теорія

## Що таке GitHub?

GitHub — це вебплатформа для зберігання файлів, керування версіями та спільної роботи над проєктами. Сервіс дозволяє розробникам, студентам та викладачам зберігати свої проєкти в репозиторіях і відстежувати зміни у файлах.

## Основні поняття

### Репозиторій (Repository)

Репозиторій — це місце для зберігання проєкту та його файлів.

### README.md

README.md — це файл з описом проєкту. Він відкривається автоматично при перегляді репозиторію.

### Issues

Issues використовуються для створення завдань, повідомлень про помилки та обговорення проєкту.

### Projects

Projects допомагають планувати роботу та відстежувати виконання завдань.

### Pull Requests

Pull Requests використовуються для внесення та перевірки змін перед їх додаванням до основної версії проєкту.
