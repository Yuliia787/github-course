# Практична робота №2

## Тема

Створення першого репозиторію та виконання коміту

## Мета роботи

- навчитися створювати репозиторії GitHub;
- ознайомитися зі структурою репозиторію;
- навчитися створювати та редагувати файли;
- виконати перший коміт;
- переглянути історію змін.

---

# 1. Коротка теорія

## Репозиторій

Репозиторій (Repository) — це місце для зберігання проєкту та його файлів.

У репозиторії можуть знаходитися:

- текстові файли;
- програмний код;
- документи;
- зображення;
- папки.

## Коміт (Commit)

Коміт — це зафіксована зміна у проєкті.

Після внесення змін користувач зберігає їх у вигляді коміту.

Кожен коміт містить:

- автора змін;
- дату та час;
- повідомлення про зміни.

Приклад повідомлення коміту:

```text
Створено файл README
```

## README.md

README.md — це головний інформаційний файл репозиторію.

Він автоматично відображається на головній сторінці репозиторію.

У README зазвичай містяться:

- назва проєкту;
- опис;
- інформація про автора;
- інструкції користувачу.

## Історія комітів

GitHub зберігає всі зміни проєкту.

Історію можна переглянути у вкладці Commit history.

# 2. Завдання

## Завдання 1

Створіть новий репозиторій з назвою:

```text
my-first-repository
```

## Завдання 2

Створіть файл README.md та додайте до нього інформацію про себе:

- прізвище та ім'я;
- група;
- спеціальність;
- хобі.

Приклад:

```markdown
# Про мене

Прізвище та ім'я: Петренко Петро

Група: КН-11

Спеціальність: Комп'ютерні науки

Хобі: футбол, музика, програмування
```

## Завдання 3

Збережіть зміни та створіть коміт із повідомленням:

```text
Створено файл README
```

## Завдання 4

Відредагуйте файл README.md.

Додайте розділ:

```markdown
## Мої улюблені навчальні дисципліни
```

та перелік щонайменше трьох предметів.

Приклад:

- Інформатика
- Математика
- Програмування

## Завдання 5

Створіть другий коміт із повідомленням:

```text
Додано улюблені дисципліни
```

## Завдання 6

Перегляньте історію комітів.

Запишіть у звіт:

- кількість комітів;
- повідомлення комітів;
- дату останнього коміту.

## Завдання 7

Надішліть викладачу посилання на створений репозиторій.

---

# 3. Інструкція з виконання

### Крок 1

Увійдіть до GitHub.

### Крок 2

Натисніть кнопку:

```text
+ → New repository
```

### Крок 3

У полі Repository name введіть:

```text
my-first-repository
```

### Крок 4

Поставте прапорець:

```text
Add a README file
```

### Крок 5

Натисніть кнопку:

```text
Create repository
```

### Крок 6

Відкрийте файл README.md.

Натисніть кнопку редагування (олівець).

### Крок 7

Додайте інформацію про себе.

### Крок 8

Натисніть:

```text
Commit changes
```

та введіть повідомлення:

```text
Створено файл README
```

### Крок 9

Знову відкрийте README.md для редагування.

### Крок 10

Додайте розділ «Мої улюблені навчальні дисципліни».

### Крок 11

Створіть другий коміт:

```text
Додано улюблені дисципліни
```

### Крок 12

Перегляньте історію комітів репозиторію.

# Контрольні запитання

1. Що таке репозиторій?
2. Для чого використовується файл README.md?
3. Що таке коміт?

5. Де переглянути історію комітів?
6. Які типи файлів можна зберігати у репозиторії?

# Результат виконання

Після виконання роботи студент повинен:

- створити власний репозиторій;
- створити та заповнити файл README.md;
- виконати не менше двох комітів;
- переглянути історію змін;
- надати викладачу посилання на репозиторій.
